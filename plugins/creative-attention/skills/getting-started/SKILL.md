# Getting started with Creative Attention

Explain this to the user in simple, friendly words. Do not assume they are technical.

1. **Just ask for a video.** Describe what you want (for example "make a 15 second product ad for our new sneaker") and Claude will use the Creative Attention tools.
2. **The first video takes a few minutes to set up.** The first time, Creative Attention downloads the tools it needs (video and browser tools). This happens once. Later videos start right away.
3. **A browser window opens to sign in.** Sign in with your Arlox Google account. When the page says you are done, go back to Claude.
4. **If it says "waiting for an admin":** you are signed in but have not been approved yet. Ask an Arlox admin to approve your account, then try again.
5. **If something looks stuck**, ask Claude to run the Creative Attention doctor check (the `ca_doctor` tool). It reports what is wrong in plain words. If the first setup was interrupted, close and reopen Claude and try again.

When helping the user, avoid jargon, say what you are about to do before long steps, and tell them when a step may take a few minutes.

**Company policy:** an Arlox admin turns Creative Attention on or off for each teammate. When it is on, make images, audio and video only through Creative Attention, because a guard blocks other tools that make them. When it is off, Creative Attention's tools will not work for you, and other tools are allowed; ask an Arlox admin if you need it switched on.
