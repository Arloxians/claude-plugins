# Creative Attention policy guard rules. Read by bin/ca-guard (sh) and `ca-launch.exe guard` (Go).
# One rule per line: <kind> <pattern>. Lines starting with # and blank lines are ignored.
# Patterns must be lowercase. Kinds:
#   tool_long    substring of the lowercased MCP tool name
#   tool_short   whole token of the tool name after suffix stripping (ai labs pro fast dev turbo max lite, trailing digits);
#                tokens come from the name as is and from the name with camelCase split (generateImage -> generate image)
#   tool_phrase  phrase matched against the space-normalised tool name tokens
#   text         lowercased substring of the hook input (envelope, file_path and notebook_path fields removed).
#                Only scanned for Bash, PowerShell, Write, Edit, MultiEdit, NotebookEdit and WebFetch; other MCP
#                tools (Slack, Notion, Gmail...) are judged by the tool_* rules alone.
#                Trailing spaces are trimmed, so a pattern cannot end with a space.
# If this file is missing or has no rules, the guard fails closed: every non-Creative-Attention MCP tool and
# every Bash/PowerShell/Write/Edit/MultiEdit/NotebookEdit/WebFetch call is a candidate.
# Never add bare words that hit normal code or prose (e.g. minimax, stability, audio, udio, diffusers, kokoro,
# chatterbox, coqui, imagen-) as text rules: use import, install, API host or model-id forms.
